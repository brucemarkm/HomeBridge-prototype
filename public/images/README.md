# Demonstration imagery

`home-0.png`, `home-1.png`, and `home-2.png` are original AI-generated architectural illustrations created for this Homebridge prototype. They depict fictional architecture and are reused across fictional listings as illustrative placeholders. They are not actual listing photographs, do not verify property facts, and should not be used as such. No external photo CDN is needed.

The typefaces are bundled via the @fontsource packages, which include their font license files in node_modules. DM Sans and Manrope use the SIL Open Font License.
